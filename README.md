# Data Science Learning Repository

This repository contains hands-on Python scripts, Jupyter notebooks, and mini projects created while learning Data Science, Machine Learning, and supporting Python concepts.

## Purpose
- Build strong Python fundamentals
- Practice data analysis and visualization
- Implement core ML algorithms from scratch
- Develop end-to-end mini projects
- Track learning progress over time

## What You Will Find
- Python basics, loops, conditions, and functions
- Data structures and OOP concepts
- Exception handling, threading, and memory management
- SQL/SQLite practice
- Exploratory Data Analysis (EDA)
- Visualization with Matplotlib and Seaborn
- ML implementations: Decision Tree, Random Forest, KNN, Naive Bayes, AdaBoost, Gradient Boosting, SVM, XGBoost, and more
- Flask and ML deployment-oriented project folders
