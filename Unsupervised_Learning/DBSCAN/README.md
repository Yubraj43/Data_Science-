# DBSCAN

This folder contains a basic DBSCAN clustering implementation.

## Files
- implementation.ipynb: starter notebook for DBSCAN clustering.

## What You Learn
1. How DBSCAN groups dense points into clusters.
2. How noise points are labeled.
3. How to tune `eps` and `min_samples`.

## Quick Steps
1. Open `implementation.ipynb`.
2. Run all cells in order.
3. Adjust `eps` and `min_samples` to see different clusters.
