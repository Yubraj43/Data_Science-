# PCA (Principal Component Analysis)

This folder contains notes and implementation practice for PCA in machine learning.

## Files
- pca_notes_math.md: mathematical intuition and formulas.
- pca_implementation.ipynb: step-by-step PCA implementation with sklearn.

## What You Learn
1. Why dimensionality reduction is useful.
2. How PCA finds directions of maximum variance.
3. How to choose the number of principal components.
4. How to visualize transformed data.

## Quick Workflow
1. Standardize features.
2. Fit PCA on training data.
3. Transform data to lower dimensions.
4. Check explained variance ratio.
5. Use transformed data for modeling or visualization.
