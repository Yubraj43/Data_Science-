# Herical Cluster

This folder contains a basic implementation of hierarchical clustering.

## Files
- implementation.ipynb: step-by-step hierarchical clustering workflow.

## What You Learn
1. Create sample data.
2. Fit Agglomerative Clustering.
3. Visualize clusters.
4. Understand linkage and number of clusters.

## Quick Start
1. Open implementation.ipynb.
2. Run cells in order.
3. Replace sample data with your dataset.
