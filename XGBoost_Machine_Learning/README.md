# XGBoost Machine Learning

This folder contains beginner-friendly material for learning and practicing XGBoost.

## Contents
- xgboost_notes.md: concept notes and key parameters.
- xgboost_implementation.ipynb: starter notebook for end-to-end model training.

## Learning Goals
1. Understand gradient boosting and how XGBoost improves it.
2. Train an XGBoost model for classification.
3. Evaluate model performance with standard metrics.
4. Tune important hyperparameters.

## Recommended Steps
1. Open the notebook.
2. Load your dataset.
3. Split into train and test sets.
4. Train XGBoost model.
5. Evaluate and tune.
