# Gradient Boosting

This folder contains notes and implementation practice for Gradient Boosting.

## Files
- gradient_boosting_notes.md: concise conceptual notes.
- gradient_boosting_implementation.ipynb: starter notebook for model training and evaluation.

## Quick Start
1. Open the notebook.
2. Load your dataset into pandas.
3. Train a Gradient Boosting model.
4. Evaluate performance with suitable metrics.
